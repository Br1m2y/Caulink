# 合规说明

## 第三方依赖

**本项目不包含任何 AGPL-3.0 代码，也没有第三方认证二进制。**

早期设计曾计划以独立子进程调用 AGPL-3.0 的 `BitSrunLoginGo` 完成校园网认证，
后经实测确认农大校园网是 Dr.COM ePortal、而非深澜（Srun），该二进制不适用，
已弃用并从仓库移除。认证协议改为自行实现（`cmd/caulink-auth`），
决策过程见 [`docs/adr/0004-drcom-auth.md`](adr/0004-drcom-auth.md)。

当前 `go.mod` 零第三方依赖。

## 使用范围

- 仅限**本人授权账号与设备**使用，遵守中国农业大学校园网使用规定。
- 不突破学校账号总配额（账号 3 台设备）；多源 IP 消耗的是使用者自己的配额。
- 不对外提供任何代理服务，不共享账号给他人。
- 所有代理与控制面仅监听 `127.0.0.1`。

## 凭据处理

- 校园网账号密码只存在使用者本机的配置文件里，**不入库**：
  `configs/*.local.*` 与 `data/` 均在 `.gitignore` 中。
- `internal/auth` 为每个源 IP 生成的实例配置权限为 `0600`、目录 `0700`。
- 程序日志不打印密码；账号在日志中脱敏为前 4 位 + `***`。
- **已知固有风险**：Dr.COM 门户的登录接口是 HTTP，密码在校园局域网内明文传输。
  这由学校门户协议决定，任何客户端（包括浏览器登录）都一样。

## 数据

- 不收集、不上传用户流量内容。
- Phase 0 测速数据只保存吞吐统计，不含报文内容，且默认不进版本库（`tools/phase0/out/`）。
