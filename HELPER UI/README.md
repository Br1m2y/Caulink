# HELPER UI · CAU WIFI HELPER 界面设计交付

本目录是「CAU WIFI HELPER」桌面客户端的界面设计与可运行原型交付物，与 `PRD.md` 配套。
原型不依赖后端、不联网、零第三方库，双击即可运行。

---

## 1. 目录结构

```
HELPER UI/
├─ 01-信息架构与线框.md   页面地图、主流程、5 张线框图、状态矩阵、交互与键盘规则
├─ 02-视觉说明.md         深色/浅色两套令牌、字号、间距、组件规格、动效、断点

└─ 预览/                  8 张界面截图（1440×900 与 1024×700）
```

## 2. 怎么打开

直接双击 `原型/index.html`（Chrome / Edge 任意现代浏览器）。
原型用普通 `<script>` 而非 ES Module，因此 `file://` 下也能跑，不需要起本地服务器。

窗口建议 1440×900；缩到 1024×700 仍是完整可用的最小尺寸。

## 3. 演示参数（地址栏加在 `index.html` 后面）

| 参数 | 作用 |
| --- | --- |
| `?theme=dark` / `?theme=light` | 指定主题，覆盖本地设置 |
| `?view=tags` / `?view=settings` | 直接打开标签管理 / 设置页 |
| `?select=1` | 预置多选，展示批量操作条 |
| `?dialog=remove` | 直接打开「从列表移除」确认弹窗 |
| `?empty=1` | 预置空状态（端口全部被忽略） |
| `?search=zzz` | 预置无结果的搜索 |

例：`原型/index.html?theme=light&view=settings`

## 4. 能点的地方

- 端口卡片 / 表格行：单击选中，`Ctrl` 多选，`Shift` 连选，上下键移动
- 工具栏：重新扫描、搜索（含无结果态）、按下载速度/延迟排序、标签筛选
- 批量条：打标签、移除（均走 400×220 居中确认弹窗）
- 账号区：登录（勾「记住密码」首次保存时弹二次确认）、清除凭据
- 表格行右键：打标签 / 复制 IP / 从列表移除
- 左上齿轮：设置页（通用行为、采集与刷新、外观、关于与诊断）
- 侧栏底部「已忽略」：恢复被隐藏的端口
- 标签管理页：新建、改名、改色（8 色）、删除（删除前提示影响端口数）

## 5. 与真实后端的对接点

原型所有数据都来自 `mock.js` 的 `window.MockAPI`，只需把这一层换成真实请求，界面层不用改：

| MockAPI 方法 | 建议对接 |
| --- | --- |
| `init()` / `scanPorts()` | `GET http://127.0.0.1:7788/api/v1/status`（字段见仓库 `docs/status-api.md`） |
| `tick()`（1s） | 同接口轮询；速率单位是**字节/秒**，界面再换算 MB/s |
| `login()` | 暂由桌面端调用认证，前端只关心 `auth_status` 变化 |
| `tags*` / `ignorePorts` / `settings` | 本机持久化，可留在前端 localStorage |

字段名与 `status-api.md` 对齐：`id`（`<网卡>@<IP>`）、`interface`、`source_ip`、`auth_status`、`health_score`、`rtt_ms`、`loss_rate`、`schedulable`、`rate_up_bps` / `rate_down_bps`、`errors`。

## 6. 已知限制（原型 ≠ 成品）

1. **标题栏**：齿轮、状态胶囊可用；最小化/最大化/关闭三个按钮只是占位，桌面端（Wails）才真正接窗口控制；拖动窗口、双击最大化需在桌面端实现。
2. **数据是模拟的**：登录有 1.2s 延迟与固定成功，速率每秒随机游走，不反映真实链路。
3. **导出**按钮禁用（第一版不做）。
4. **不联网**：没有真实认证、没有真实网卡扫描；端口是 3 个固定 mock（WLAN / 以太网 / 以太网 2）。
5. **设置项**中「开机自启」等桌面专属项只保存到 localStorage，不会真的改系统设置。
6. 剪贴板复制依赖浏览器权限，`file://` 下某些环境会提示「复制失败」，属预期。
