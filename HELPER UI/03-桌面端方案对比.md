## 2. 三条路线

| | A. Wails v3 接入仓库 | B. Wails v3 独立副本 | C. Electron |
| --- | --- | --- | --- |
| 产物 | `caulink-desktop.exe`，~10–20MB | 同 A | 安装包/免安装目录，100–200MB |
| 需装 | Go + mingw-w64 + wails3 | 同 A | Node.js（npm 依赖几百 MB，但不用 C 编译器） |
| 前端改动 | 已完成（`desktop/frontend/app/`，比原型多 `api.js` 与 `shell.js`） | 同 A | 几乎为零 |
| 窗口控制 | Wails frameless + 自绘标题栏，三键真能点 | 同 A | `BrowserWindow({frame:false})`，三键真能点 |
| 与仓库一致 | ✅ 符合 `docs/adr/0002-ui-framework-wails.md` | ✅ 最终合入后一致 | ❌ 与 ADR 冲突 |
| 动到共用仓库 | 直接改 `desktop/`（需与其他作者协调） | 先不改，验证后一次合入 | 需新增 `desktop-electron/` |
| 风险 | cgo 环境 + Windows 上 Wails 仍需 C 编译器，`wails3 doctor` 要过 | 同 A，但不阻塞别人 | 产物大、与团队决策相悖 |

> 备注：Wails 是否真的需要 mingw 取决于 `wails3 doctor` 的当前要求，装完工具链第一步就跑它确认，不靠猜。

### A / B 的落地步骤（选一个执行）

1. 装 Go（`winget install GoLang.Go` 或官方 zip）→ 配 `GOPATH`/`PATH`
2. 装 mingw-w64（MSYS2 或 `winget install BrechtSanders.WinLibs.POSIX.UCRT`）
3. `go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0` → `wails3 doctor`
4. Wails 工程已落在 `desktop/`（历史上曾用 `scripts/init-desktop.sh` 或手工生成）
5. 原型与桌面端前端同源：`HELPER UI/原型/` 是设计稿，`desktop/frontend/app/` 是交付物
6. `mock.js` 换成 `fetch('http://127.0.0.1:7788/api/v1/status')` + 1s 轮询 / 3s 超时；字段照 `docs/status-api.md`
7. 标题栏三键接 Wails window API（minimise / toggle maximise / close），加拖动区域
8. `wails3 build` → 双击 exe 验证：状态刷新、登录、标签、设置持久化

### C 的落地步骤

1. 装 Node LTS
2. `npm init -y` + `npm i -D electron electron-builder`
3. `main.js`：`new BrowserWindow({ width:1440, height:900, minWidth:1024, minHeight:700, frame:false, webPreferences:{preload} })`
4. 页面加载 `HELPER UI/原型/index.html`；preload 暴露 `window.__desk = { minimize, maximize, close }` 给标题栏三键
5. `npx electron .` 跑通 → `electron-builder --win portable` 出 exe

## 3. 还有一条零安装的过渡路（不算正式方案）

用 Edge 的 `--app` 模式：`msedge --app="file:///<仓库根目录>/HELPER UI/原型/index.html" --window-size=1440,900`
双击快捷方式就是一个没有地址栏的独立窗口。**只适合临时演示**，不是可分发的程序，窗口三键也就失效了。
