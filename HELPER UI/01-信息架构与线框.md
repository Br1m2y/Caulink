# 01 · 信息架构与线框

> 阅读顺序：本文（骨架）→ `02-视觉说明.md`（外皮）→ `原型/index.html`（能跑的东西）。
> 需求依据：仓库根目录 `PRD.md`（D01–D23 决策、K01–K51 控件、AC-01–AC-30 验收）。

---

## 1. 一句话定位

给一台机器多个网卡、多条出口的校园网用户，一个"现在从哪出去、通不通、多快"的仪表盘，外加一条**登录 → 选路 → 排障**的最短操作链。

## 2. 谁在用、什么时候用

| 场景 | 用户状态 | 界面要给的东西 |
|---|---|---|
| 开机连网 | 急着上网 | 一眼看到"已连接/未连接"，账号框可立即输入，登录两步走完 |
| 网速变慢 | 困惑，怀疑某条线坏了 | 哪个端口异常、异常原因、丢包率与延迟是否在抖 |
| 临时接网线 | 多了一块网卡 | 自动扫出来、可打标签归类、可暂时忽略不想看的口 |

三种场景对应三个区域：**认证区**（急）、**统计区+表格**（疑惑）、**侧栏+标签**（整理）。

## 3. 信息架构

```

│
├─ 主界面  #/                       ← 唯一主视图，默认进入
│  ├─ 标题栏

│  │  ├─ 连接状态胶囊        ← 读主用端口 auth_status
│  │  ├─ 设置入口（齿轮）    ← 全应用唯一入口
│  │  └─ 窗口控制（桌面端生效）
│  │
│  ├─ 端口侧栏 300px
│  │  ├─ 区头：端口 / ⟳ 重新扫描
│  │  ├─ 搜索框              ← 匹配网卡名、IP、标签
│  │  ├─ 批量操作条          ← 多选时浮出：打标签 / 移除 / 计数
│  │  ├─ 端口卡片列表        ← 状态灯、名、速率、IP·型号、标签

│  │
│  └─ 主内容区
│     ├─ 统计区（5 卡）
│     │  ├─ 正常端口
│     │  ├─ 异常端口
│     │  ├─ 当前网速
│     │  ├─ 延迟
│     │  └─ 丢包率          ← 主用端口口径
│     ├─ 账号区（一行）
│     │  ├─ 账号 / 密码（含显示切换）
│     │  ├─ 记住密码
│     │  ├─ 登录 / 清除凭据
│     │  └─ 安全说明
│     └─ 端口状态区
│        ├─ 区头：标题 / 刷新说明 / 筛选标签 / 导出（暂置灰）
│        ├─ 表格：端口·状态·下载速度·延迟·标签·行操作
│        ├─ 近 60 秒下行速率曲线
│        └─ 空态 / 筛选无结果态
│
├─ 标签管理  #/tags
│  ├─ 返回 + 标题 + 新建
│  ├─ 说明行
│  └─ 标签行：色点 / 名称 / 已用端口数 / 改色 / 改名 / 删除
│
├─ 设置  #/settings
│  ├─ 通用行为（3 开关）
│  ├─ 采集与刷新（轮询间隔 / 超时）
│  ├─ 外观（深色 / 浅色）
│  └─ 关于与诊断（版本 / 日志 / 配置 / 更新 / 恢复默认）
│
└─ 弹窗层（400×220，居中）
   ├─ 移除端口确认
   ├─ 保存凭据确认
   ├─ 清除凭据确认
   ├─ 删除标签确认
   ├─ 批量打标签
   └─ 已忽略端口管理
```

**层级原则**

1. 主界面永远是"当前状态"的家；标签与设置是"配置"，必须能一键返回。
2. 弹窗只装**不可逆或涉及凭据**的动作，普通操作用行内反馈（toast）。
3. 端口是唯一实体的锚点：侧栏、表格、标签、曲线都按 `端口 id` 关联。

## 4. 三条主流程

### 4.1 登录（急）

```
进入主界面
   │
   ├─ 已有凭据 ──→ 账号已填充、密码掩码 ──→ 点「登录」
   │                                        │
   └─ 无凭据 ──→ 输入账号密码 ──→ 勾了「记住密码」？
                                    ├─ 是 → 确认弹窗 → 保存并登录
                                    └─ 否 → 直接登录
                                             │
                                     按钮 loading 1.2s
                                             │
                                 ├─ 成功 → 主用端口变「正常」、胶囊「已连接」、toast
                                 └─ 失败 → 行内红字原因 + toast，密码保留
```

### 4.2 排障（疑惑）

```
发现网速慢
   │
   ├─ 看统计区：延迟/丢包是否在抖 ──→ 看曲线
   ├─ 看异常端口卡：脚注写着首个异常原因
   └─ 点端口 → 表格高亮 → 行状态与错误信息 → 决定：重登 / 换口 / 忽略
```

### 4.3 整理（顺手）

```
插入新网卡 ──→ ⟳ 重新扫描 ──→ 列表多出一张卡
                                  │
                    右键 / 行菜单 ──→ 打标签（宿舍/实验室/备用）
                                  │
                            Ctrl 多选 ──→ 批量打标签 / 批量移除
```

## 6. 状态矩阵

| 区域 | 加载中 | 空 | 筛选无结果 | 出错 |
|---|---|---|---|---|
| 端口侧栏 | 3 行骨架 | "未检测到可用端口" + 重新扫描 | "没有匹配「x」的端口" + 清除 | 骨架保持 + toast |
| 统计区 | 数值 `—` | 全 `—` | 不受筛选影响，始终反映全局 | 保留上次值，角标"数据延迟" |
| 账号区 | 登录按钮转圈 | 无凭据：空输入 + 清除置灰 | — | 行内红字原因 |
| 表格 | 3 行骨架 | 同侧栏空态 | "没有符合条件的端口" + 清除筛选 | 行内显示 errors[0] |
| 曲线 | 灰底提示"等待数据" | 隐藏 | 隐藏 | 断点保留，不画假线 |

## 7. 交互规则

| 规则 | 说明 |
|---|---|
| 选择 | 单击单选；Ctrl 切换；Shift 从锚点到当前连选；点击空白处清空 |
| 排序 | 表头"下载速度""延迟"可切升降序；默认下载速度降序 |
| 筛选 | 搜索词与标签筛选**同时**生效（取交集），任一命中即显示"清除筛选" |
| 刷新 | 每秒拉一次状态；只有数字与曲线更新，**不重建 DOM**（避免选中态丢失） |
| 忽略 | 只从列表隐藏，`localStorage` 记录；恢复时保留原有标签 |
| 标签 | 一名一色；重名拒绝并提示；删除时二次确认并写明影响端口数 |
| 主题 | 只切换 CSS 变量，无闪烁、无需重载 |

## 8. 键盘与可达性

| 键 | 行为 |
|---|---|
| Tab / Shift+Tab | 依次到达：搜索 → 端口卡片 → 批量按钮 → 账号 → 密码 → 记住 → 登录 → 清除 → 表头 → 行 → 筛选 → 导出 → 链接 |
| Enter / Space | 触发当前控件；端口卡片与表格行等同按钮 |
| Esc | 关闭弹窗 / 清空搜索焦点 |
| Ctrl+A | 列表内全选（可选，不做也接受） |

所有 focus 使用 2px 描边（`outline: 2px solid var(--accent); outline-offset: 2px`），不用 `outline:none`。
