# 02 · 视觉说明

> 前三张对比稿（`../_shots/`）定的是方向：深色仪表盘胜出，标题栏自绘。
> 本文把方向落成可执行的数值——颜色、字号、间距、组件、动效，原型里全部按这里实现。

---

## 1. 为什么是深色

这个软件 90% 的时间在**后台长跑**，用户抬头看它一眼的场景是"网卡了"。深色底能把注意力压到两处：**状态点**和**数字**；浅色底在同样信息密度下会显得吵。因此深色为默认，浅色作为"白天/投屏"备选，两套共用同一套变量，只是取值不同。

## 2. 设计令牌

### 2.1 颜色

| 令牌 | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `#0d1015` | `#f2f4f8` | 窗口底色 |
| `--panel` | `#11151c` | `#ffffff` | 侧栏、标题栏 |
| `--card` | `#161b23` | `#ffffff` | 卡片、表格容器 |
| `--card-2` | `#1a202a` | `#f7f9fc` | 卡内嵌块（输入框、行 hover） |
| `--line` | `#232a35` | `#e3e8ef` | 1px 分割线 |
| `--text` | `#e8ecf3` | `#151a21` | 主文字 |
| `--muted` | `#8c96a7` | `#5f6875` | 次要文字、表头 |
| `--faint` | `#5f6b7c` | `#8b95a3` | 脚注、单位 |
| `--accent` | `#4a8cff` | `#2f6fed` | 主按钮、选中态、曲线 |
| `--ok` | `#35d39a` | `#0f9f5f` | 正常、在线 |
| `--bad` | `#ff6b6b` | `#e0484d` | 异常、失败、危险操作 |
| `--warn` | `#f2b544` | `#c98616` | 认证中、注意 |
| `--accent-weak` | `rgba(74,140,255,.14)` | `rgba(47,111,237,.10)` | 选中行底、chip 底 |

对比度自查：`--text` on `--card` ≈ 13.4:1（深）/ 14.8:1（浅）；`--muted` on `--card` ≈ 5.6:1；`--ok`/`--bad` 在各自底上均 ≥ 4.5:1。数字用主文字色，不拿彩色写字（彩色只给点和徽标）。

### 2.2 字体与字号

字体栈：`"Segoe UI", "Microsoft YaHei UI", "PingFang SC", system-ui, sans-serif`；数字用等宽变体 `font-variant-numeric: tabular-nums`，避免每秒刷新时数字跳动。

| 层级 | 字号/行高 | 字重 | 用法 |
|---|---|---|---|
| 统计数值 | 24 / 1.05 | 650 | 5 张卡的主数字 |
| 页面标题 | 17 / 1.3 | 600 | 标签管理、设置 |
| 卡片数值（行内） | 13.5 | 600 | 表格里的速率、延迟 |
| 正文 | 13 / 1.5 | 400 | 说明、表格内容 |
| 表头 | 11.5 / 1.2 | 500 | 列名，`--muted`，字距 .02em |
| 标签卡 | 11 | 400 | 脚注、单位、时间 |
| 徽标/chip | 11 / 1 | 500 | 状态、标签 |

**不用** 10px 以下的字；1024 宽时只改布局，不改字号（AC-03）。

### 2.3 间距与尺寸

| 项 | 值 |
|---|---|
| 基准单位 | 2px（实际用 2 / 4 / 6 / 8 / 10 / 14 / 18 / 24） |
| 窗口内边距 | 主内容 24px，侧栏 16px，卡片内 18px |
| 区块间距 | 14px |
| 统计卡间距 | 10px |
| 圆角 | 卡片 12px、统计卡 10px、按钮 8px、输入 8px、chip 5px、胶囊 999px |
| 边框 | 统一 1px `var(--line)`；选中态用 1px `--accent` + 2px 内阴影，不加粗边框（避免跳动） |
| 阴影 | 深色不用投影，用 `--line` 分割；仅弹窗用 `0 24px 60px rgba(0,0,0,.55)` |

### 2.4 布局刻度

| 区 | 尺寸 | 弹性 |
|---|---|---|
| 标题栏 | 56px 高，通栏 | 固定 |
| 端口侧栏 | 300px 宽 | 固定，1024 下不缩 |
| 主内容 | 剩余宽度 − 48px 内边距 | 弹性 |
| 统计区 | 高 104px | 5 列；容器 < 1180px 时 3 列 |
| 账号区 | 高 62px | 一行 |
| 表格卡片 | 撑满剩余高度，最小 260px | 表格滚动，曲线固定 150px |

## 3. 组件规格

### 3.1 统计卡

```
┌──────────────────────────────┐
│ ● 正常端口            [badge] │  ← 11px 标签 + 6px 状态点
│ 1 个                          │  ← 24px 数值；单位 11px，基线对齐，距数值 4px
│ 共 3 个，2 个未就绪            │  ← 11px --muted，单行 ellipsis
└──────────────────────────────┘
```
- 内边距 14px 16px；背景 `--card`；圆角 10px；边框 1px `--line`。
- 数值超长时缩单位不缩数字（`12.4` 保留一位小数，单位随量级变）。
- 异常数 > 0 时状态点做 2s 一次的 1→1.25 倍脉冲，`prefers-reduced-motion` 下静止。

### 3.2 端口卡片（侧栏）

- 高 78px，内边距 10px 12px，圆角 9px，默认透明 + 1px transparent 边框。
- 结构：`[状态点] 网卡名 ………… 速率` / `IP · 型号` / `chips`。
- 悬停：底 `--card`；选中：底 `--accent-weak` + 左边 3px `--accent` 竖条（用 `box-shadow: inset 3px 0 0`，不影响布局）。
- 被忽略的端口不出现在列表里，脚注给入口。

### 3.3 表格

- 表头 34px，`position: sticky; top:0`，底 `--card` + 下边框。
- 行高 44px，行间用 1px `--line` 分隔，不用斑马纹（深色下斑马纹会脏）。
- 端口单元格两行：名字 13px / IP 11px `--faint`。
- 状态用**胶囊徽标**：`正常`绿、`未连接`灰、`认证失败`红、`认证中`黄。
- 行操作 `⋯` 常驻但低对比，hover 行时提亮。

### 3.4 输入与按钮

| 控件 | 规格 |
|---|---|
| 输入框 | 高 34px，底 `--card-2`，1px `--line`，focus 时 1px `--accent` + `0 0 0 3px --accent-weak` |
| 主按钮 | 高 34px，底 `--accent`，字 `#fff`，hover 提亮 6%，active 下沉 1px |
| 次按钮 | 透明底 + 1px `--line`，hover 底 `--card-2` |
| 危险按钮 | 透明底 + `--bad` 文字与边框；hover 底 `rgba(255,107,107,.12)` |
| 图标按钮 | 30×30，圆角 8px，hover 底 `--card-2` |
| 开关 | 34×20 圆角 999px，开启 `--accent`，滑块 16px 带 120ms 位移 |

### 3.5 弹窗

- 尺寸固定 400×220（内容更多时内部滚动，不改尺寸——AC 要求"统一"）。
- 结构：标题 16px/600 → 正文 13px/1.6 `--muted`（最多 4 行，超出滚动）→ 右对齐按钮组。
- 遮罩 `rgba(6,8,12,.55)`（浅色下 `.35`），居中，出现动画 120ms 上浮 6px + 淡入。
- 焦点默认在主按钮；Esc / 遮罩 / ✕ 都等于取消。

### 3.6 曲线

- 高 150px，SVG，`preserveAspectRatio="none"` 只在面积层使用，描边层用固定 viewBox 防拉伸变形。
- 线 1.5px `--accent`；面积填充 `--accent` 12% → 0 的线性渐变。
- 三条水平参考线（25/50/75%）用 1px 虚线 `--line`。
- 悬停十字线 + tooltip（时间、速率），跟随鼠标但不出卡。

## 4. 图标

内联 SVG，24×24 viewBox，`stroke: currentColor; stroke-width: 1.6; fill: none`，圆头端点。需要的图标只有：齿轮、刷新、搜索、关闭、最小化、最大化、还原、眼睛、⋯、＋、🗑、✎、返回、勾、警告。**不引图标字体**（离线可用）。

## 5. 动效

| 场景 | 时长/曲线 |
|---|---|
| 数字变化 | 220ms，缓出；只做 opacity + translateY(2px) 的小换字，不滚动计数 |
| 选中/悬停 | 90ms ease-out，只过渡 background/border-color |
| 弹窗 | 120ms，`cubic-bezier(.2,.8,.3,1)` |
| 骨架 | 1.2s 循环，亮度 6% → 12% |
| 状态点脉冲 | 2s ease-in-out 无限（仅异常） |

统一尊重 `prefers-reduced-motion: reduce`：去掉位移与脉冲，保留透明度变化。

## 6. 主题切换

`<body data-theme="dark|light">` 切换，只换 CSS 变量，不重载、不闪烁。窗口背景色同步设置 `background: var(--bg)`，避免切换瞬间白闪。

## 7. 自适应断点

| 断点 | 触发 | 变化 |
|---|---|---|
| `max-width: 1180px` | 统计区容器不足 | 5 卡 → 3 列（第二行 2 张） |
| `max-width: 1180px` | 表格宽度 | 隐藏"标签"列，标签改在端口单元格换行展示 |
| `max-width: 900px` | 非目标平台 | 侧栏折叠为 88px 图标栏（原型里仅做展示，实际最小 1024） |

只做这三个断点，不做移动端。

## 8. 文案与语气

- 全中文，动词开头："重新扫描""保存并登录""清除凭据"。
- 说明句不超过两行，把后果写在动作后：「只从列表隐藏，可恢复」。
- 不用感叹号，不用"请"字堆叠；错误直接说原因：「账号或密码不正确」。
